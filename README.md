# Password Generator (Schulprojekt)

**Hinweis:** Dieses npm-Modul wurde im Rahmen eines Schulprojekts erstellt. Es dient ausschließlich zu Lern- und Übungszwecken. Bitte nicht für produktive Anwendungen verwenden.

## Funktionen

Ein einfacher Passwortgenerator mit folgenden Einstellungsmöglichkeiten:
- Passwortlänge frei wählen
- Sonderzeichen optional aktivieren
- Standardmäßig 8 Zeichen ohne Sonderzeichen
